# 分析与建议

## 先核验数据

只检查与问题相关的数据：覆盖时间与新鲜度、行粒度、主键唯一性、缺失/重复、异常值、状态编码、币种/单位及时区。关联表前核对连接键和一对多关系，比较关联前后的行数与关键汇总，避免重复累计。

明确总体、样本及筛选规则。截断结果不能代表总体；抽样估计须说明抽样设计、适用总体和不确定性，不能当成精确总量。需要精确总体指标时在数据库侧聚合。区分零值、空值、未知和无数据，不把未完成周期与完整周期直接比较。

## 分析与复核

围绕决策先做基线、趋势和最能解释变化的分层，再扩展方法。保留绝对量与相对变化，区分百分点与百分比；小样本给出不确定性。多次筛选后发现的差异标为探索结果，重要结论用独立时期、对照或实验复核。

每个主要发现至少核对一项：与已知业务汇总对账、独立查询复算、边界样例或替代口径敏感性。结果冲突先排查口径、刷新时间、关联放大和截断；无法消除时保留冲突，不挑选最符合预期的数字。

## 从证据形成建议

每条建议连通“发现 → 业务含义 → 可采取的行动 → 验证办法”。比较必要选项的收益假设、成本/依赖、风险和可逆性；优先给最有价值的下一步，不输出长串泛化建议。

- 观察：数据直接支持的现象，附时间范围和口径。
- 解释：可能机制及替代解释，说明可信程度。
- 建议：行动和适用条件，不能写成已批准承诺。
- 验证：衡量指标、对照、观察周期、继续/停止条件；未知阈值待确认。

没有足够证据时给“目前能判断什么、不能判断什么、最小补充数据或试验”，不把无法证实写成没有问题。收益测算列公式、基准和假设区间，不把测算当实际收益。

## 最小可复核证据

重要分析在内部证据附件中保留：

- 数据库/连接的非敏感别名、相关表或视图、提取时间和数据截止时间；
- 指标口径、区间与时区、过滤条件、连接/去重规则；
- 已脱敏的查询与参数、计算方法或脚本、必要汇总结果及校验；
- 抽样、截断、缓存、刷新延迟、跨查询一致性及其他局限。

可复核不等于保存全量明细。优先保留聚合和必要哈希；不能留存的数据按授权范围处理，不擅自归档。内部材料标明“内部材料”，凭证及敏感参数不得进入附件。

按主工作流登记最小必要证据，摘要和定位信息不含凭证；用来源关联交付物或 Wiki，不以原始数据替代已确认的项目事实。

## 对客户表达

正文先给建议、关键数字、业务影响，再给主要限制和验证行动。图表标注单位、时间、样本/总体、比较口径与来源名称。内部查询、表名、路径、ID 和连接信息放在内部附件，不进入客户正文；无法公开的来源使用经允许的业务名称。
