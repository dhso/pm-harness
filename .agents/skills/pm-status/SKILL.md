# 维护项目状态

按本次事项查询相关计划、登记册、交付物、活动和收件箱；汇总报告覆盖所问周期与范围。

| 任务 | 流程 |
|---|---|
| 会议纪要 | 读[纪要联动](references/meeting-minutes.md)；返回纪要、已同步对象与待确认/待审批项 |
| 进度、行动、风险、问题或决定 | 读[状态同步](references/status-update.md)；返回事实变化、证据和未解决事项 |
| 状态报告 | 核对事实状态；需同步新进展时先执行状态同步，再将事实与受众交给 `pm-communication`，返回报告文本 |

子流程返回后由本流程汇报并按 `AGENTS.md` 收尾。仅起草或汇总已有记录时直接返回文本，不制造新的进展或活动。
