# 状态同步

输入：本次进展或事项、相关对象和来源；仅补查影响更新的缺口。

| 事项 | 操作 |
|---|---|
| 进度或行动项 | 按[计划更新时间](../../../../.harness/references/schedule-policy.md#更新时间)更新任务/里程碑，保留依赖、证据和下一步 |
| 风险、问题或决定 | 先查同类登记项，按 `register.upsert` 契约更新状态、负责人、影响、应对/解决情况及来源；不猜测批准或关闭事件 |
| 受控业务变化 | 按[变更控制](../../../../.harness/references/change-control.md)处理，未获批部分保留提议，不混入已应用事实 |

这些事项可组合；一次确认涉及多个对象时按依赖顺序组成一个 `workflow.apply`。受影响事实、精简活动及需更新的状态/当前记忆、同次已确认偏好一起原子提交；偏好操作遵循 `AGENTS.md`。

会议同步复用上述原子提交要求，具体确认与条目处理按[纪要联动](meeting-minutes.md)；不再另建或嵌套工作流。失败按 `code`、`fix` 处理，未提交内容不表述为已更新。

返回事实变化、必要证据和未解决事项，由调用方按 `AGENTS.md` 统一收尾。
