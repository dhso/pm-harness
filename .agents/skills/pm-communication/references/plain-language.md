# 说人话与保真

## 保真

```text
事实账本 = 主体/职责 + 已做/未做/下一步 + 数字及对象 + 日期/时区/顺序
         + 范围/条件/例外/否定/不确定性 + 状态 + 风险/影响/依赖/来源
区分事实、判断、建议、承诺和待确认项 → 按受众成稿
```

歧义标为待确认，不补造姓名、数量、日期、因果或批准。保留正式术语、指标名、必要原话、责任边界和语气强度；建议、预测、目标、承诺以及完成、批准、发送、交付、验收分别表述。

## 对外呈现

遵循 `AGENTS.md`：对外正文、标题、页面、图表与附件使用业务名称，不暴露内部 ID、路径、操作或工作流字段。内部追踪信息留在标明“内部材料”的版本；对方明确需要追踪时，只放双方约定的独立追踪表，不进入正文或页面主体。

术语按语境翻译：基线 → 原定/已批准的计划；预测 → 目前预计；交付物 → 文件/成果。受控变更按真实状态写为“变更提议”或“经批准的变更”，不因改写暗示批准。受众熟悉的行业术语可保留。

## 表达与层次

- 直接写结论、请求或变化；用明确主语和动作，删铺垫、空总结及无动作的黑话，保留项目正式术语。
- 同一对象保持同一称呼，语气和专业程度匹配受众；不以口语化为目标，不虚构“数据显示”等依据。
- 开头：结论、影响、请求和期限；正文：关键事实、原因、负责人和下一步；后段/附件：时间线、数据和来源。只保留本次所需层次，不用“详见附件”代替正文的结论或请求。

## 有限复核

成稿后核对一次：主体、数字、日期、范围、条件、否定、状态及术语是否遗漏或变义；事实、因果、承诺和评价是否可追溯；责任人、期限、影响和下一步是否因压缩丢失。

发现具体问题才定点修改；已自然准确的文本不反复重写。默认不展示事实账本或复核过程。
