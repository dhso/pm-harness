# 项目汇报写作

| 形态 | 内容脚手架 |
|---|---|
| 周报、阶段状态 | `templates/status-report.md` |
| 管理层简报、决策材料 | `templates/executive-brief.md` |
| 专项分析 | 执行摘要 → 事实与范围 → 分析 → 建议 → 行动计划 → 附录 |

```text
标题/周期
摘要 = 当前结论 + 相对目标/基线的变化 + 主要风险/机会 + 所需决定/支持 + 下一关键日期
正文 = 成果/证据 + 里程碑基线/预测/实际偏差 + 风险/问题/依赖及负责人
     + 已确认决定/待决事项 + 下一阶段行动/负责人/日期
附录 = 必要时间线、明细、来源和方法
```

只展开适用项。摘要能独立阅读，数字和范围可回指正文或来源；进展说明结果与影响，不复制活动流水账。

| 状态表述 | 必要依据 |
|---|---|
| 完成 | 结果或证据 |
| 按计划 | 与基线或当前承诺对照 |
| 延期 | 原日期、当前预测、影响 |
| 有风险 | 触发条件、概率或紧迫程度、影响、应对 |
| 等待支持 | 谁在何时提供什么 |

没有约定红黄绿标准时写事实和偏差，不自行给颜色。基线、预测、实际、目标和承诺分别表述；保真、表达及对外边界沿用[说人话与保真](plain-language.md)。
