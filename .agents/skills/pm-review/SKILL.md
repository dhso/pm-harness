# 评审结果

识别适用的目标、需求、验收标准、决定或交付物说明。依据这些来源评审，不凭一般偏好判断。

| 分支 | 子流程与返回结果 |
|---|---|
| 质量检查或整改复验 | [质量检查](references/quality-review.md) → 适用范围、结论、发现和证据 |
| 正式验收 | 质量检查 + [交付物政策](../../../.harness/references/deliverable-policy.md)中的授权与事件条件 → 验收结论或待确认项 |
| 复盘 | 按下述复盘流程 → 后续行动、长期经验或待决事项 |

先报告重要缺口及证据、影响。轻量评审按质量参考直接返回结论，不额外建立报告、测试矩阵或审批。

复盘时使用 `templates/retrospective.md`。比较基线、预测、实际结果、需求变化、风险、决定、交付证据和活动。区分可复用的流程经验与一次性情况。

需执行跟踪的后续行动交给 `pm-planning`；产生长期经验时按[演进政策](../../../.harness/references/evolution-policy.md)区分观察、偏好与规则提案。返回已记录对象与待决定事项，由本流程按 `AGENTS.md` 收尾。
