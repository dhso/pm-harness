# DBX 只读分析

业务问题、指标和结论由主工作流负责，本能力提供数据库结构和查询结果。

## 使用前

- 先检查 `dbx --version`；CLI 缺失时，取得安装授权后运行 `npm install --global @dbx-app/cli`，再复查版本。
- 连接在 [DBX 客户端](https://github.com/t8y2/dbx)配置；客户端缺失时引导安装。

## 查询流程

1. 读取[命令参考](references/commands.md)，以安装版本帮助为准。
2. 使用用户指定的连接；未指定时列出候选，匹配唯一且用途一致时复用，存在歧义则询问。
3. 只探索相关表、列和键，核验结构与指标口径后编写单条查询。
4. 执行前读取[只读边界](references/safety.md)。从项目根运行任务目录中的查询文件，默认 `--limit 50 --timeout 10s --json`；更严格的连接策略优先。
5. 核对返回结果、行数与截断状态，失败按命令参考处理。

## 固定边界

- 不添加 `--allow-writes`、`--allow-dangerous-sql`，不关闭保护或改用其他工具执行被拦截的内容。
- `dbx query` 不提供有状态多步会话，多次调用不能视为同一事务。需要一致快照时使用已授权的固定数据截面；无法满足时说明限制并停在查询设计。
- 返回行数限制不能限制扫描、费用或结果字节；先用明确列、时间过滤和源端聚合控制负载，必要保护无法满足时停止执行。

## 交接

返回非敏感连接别名、查询依据、提取时间、数据截止时间、返回行数及限制，未知项标明未知。只有成功执行并核验的结果可作证据；证据留存和任务目录清理由主工作流负责。
