# Git 最小必要事实集

## 应追踪

Harness 指令、实体 `.agents/skills/`、可执行契约、项目事实、需求/计划/风险/决策、结构化来源与证据、精选 Wiki、当前和批准交付物、结构化索引、活动事实与生成视图、记忆和项目规则。

## 不应追踪

原始邮件/聊天/截图/附件、历史草稿和旧二进制、渲染文件、缓存、备份、临时文件、完整聊天或工具日志、凭证和秘密。原始资料被排除是为了控制仓库体积与噪声，不要求对正常项目内容做脱敏。

归档文件放在 `archive/files/`，但 `archive/index.json` 留在 Git。每条索引使用稳定 `ARC-###`，并至少保存所归档对象的逻辑 ID、文件名、类型、SHA-256、归档时间、原因、替代对象和可用状态。

Git 已存在时可读取差异帮助复核，但不得擅自初始化、提交、推送、清理或改写历史。

Markdown、JSON 和 MJS 统一使用 LF。模板不得追踪软链接；下载压缩包或复制到 Windows 后必须仍能发现全部 Skills。
